# Agentes — Português (Brasil)

Este diretório contém documentação sobre agentes de exemplo e como usá-los.

O que você encontrará aqui:
- Instruções para usar agentes de exemplo
- Como contribuir com traduções e exemplos

Como usar
1. Abra a pasta do seu idioma (../pt-BR, ../en, etc.).
2. Leia as instruções no seu idioma.
3. Se houver scripts de exemplo, siga os comandos de execução no arquivo.
4. Para contribuir: edite ou adicione agents/<lang>/README.md e crie um pull request.

Exemplos
- Atualmente não há agentes executáveis neste repositório. Você pode adicionar exemplos em agents/examples/<language>/.
