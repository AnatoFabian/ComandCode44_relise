# Agents — English

This directory contains information about example agents and how to use them.

What you'll find here:
- Instructions for using example agents
- How to contribute translations and examples

How to use
1. Open the folder for your language (../en, ../ru, etc.).
2. Read the instructions in your language.
3. If example scripts are provided, follow the run commands in the file.
4. To contribute: edit or add agents/<lang>/README.md and create a pull request.

Examples
- Currently there are no runnable example agents inside this repository. You can add examples in agents/examples/<language>/.
