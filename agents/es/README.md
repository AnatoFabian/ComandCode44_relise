# Agentes — Español

Este directorio contiene documentación sobre agentes de ejemplo y cómo usarlos.

Qué encontrarás aquí:
- Instrucciones para usar los agentes de ejemplo
- Cómo contribuir con traducciones y ejemplos

Cómo usar
1. Abre la carpeta de tu idioma (../es, ../en, etc.).
2. Lee las instrucciones en tu idioma.
3. Si hay scripts de ejemplo, sigue los comandos de ejecución en el archivo.
4. Para contribuir: edita o añade agents/<lang>/README.md y crea un pull request.

Ejemplos
- Actualmente no hay agentes ejecutables en este repositorio. Puedes agregar ejemplos en agents/examples/<language>/.
