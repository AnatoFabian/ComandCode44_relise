# Agenten — Deutsch

Dieses Verzeichnis enthält Informationen über Beispielagenten und deren Verwendung.

Inhalt:
- Anleitungen zur Nutzung von Beispielagenten
- Wie man Beiträge leistet: Übersetzungen und Beispiele

Anleitung
1. Öffnen Sie den Ordner für Ihre Sprache (../de, ../en usw.).
2. Lesen Sie die Anleitung in Ihrer Sprache.
3. Falls Beispielskripte vorhanden sind, führen Sie diese nach den Anweisungen aus.
4. Um beizutragen: bearbeiten oder fügen Sie agents/<lang>/README.md hinzu und erstellen Sie einen Pull Request.

Beispiele
- Im Repository sind derzeit keine ausführbaren Beispielagenten enthalten. Sie können Beispiele in agents/examples/<language>/ hinzufügen.
