# Agents — Français

Ce répertoire contient la documentation concernant des agents exemples et comment les utiliser.

Ce que vous trouverez ici :
- Instructions pour utiliser les agents exemples
- Comment contribuer : traductions et exemples

Comment utiliser
1. Ouvrez le dossier de votre langue (../fr, ../en, etc.).
2. Lisez les instructions dans votre langue.
3. Si des scripts d'exemple sont fournis, suivez les commandes d'exécution indiquées.
4. Pour contribuer : modifiez ou ajoutez agents/<lang>/README.md puis créez une pull request.

Exemples
- Il n'y a actuellement pas d'agents exécutables dans ce dépôt. Vous pouvez ajouter des exemples dans agents/examples/<language>/.
