使用方法
1. 打开对应语言的文件夹（../zh-CN, ../en 等）。
2. 阅读该语言的说明。
3. 如果提供了示例脚本，请按文件中的运行命令执行。
4. 要贡献翻译或示例：编辑或添加 agents/<lang>/README.md 并创建 Pull Request。

示例
- 当前仓库中尚无可运行的示例代理。你可以在 agents/examples/<language>/ 添加示例。
