# Агенты — Русский

В этой папке находится документация по примерам агентов и инструкции по их использованию.

Содержимое:
- Инструкции по использованию примеров агентов
- Как внести вклад: переводы и примеры кода

Как пользоваться
1. Откройте подпапку с вашим языком (../ru, ../en и т.д.).
2. Прочитайте инструкцию на вашем языке.
3. Если присутствуют скрипты-примеры, запустите их согласно командам в файле.
4. Чтобы внести вклад: отредактируйте или добавьте agents/<lang>/README.md и создайте pull request.

Примеры
- В репозитории пока нет запускаемых примеров агентов. Вы можете добавить примеры в agents/examples/<language>/.
