# エージェント — 日本語

このディレクトリには、サンプルエージェントに関するドキュメントと使用方法が含まれています。

内容:
- サンプルエージェントの使用手順
- 翻訳やサンプルコードの貢献方法

使い方
1. 自分の言語のフォルダを開いてください（../ja, ../en など）。
2. 自分の言語で説明を読みます。
3. サンプルスクリプトがある場合は、ファイル内の実行コマンドに従ってください。
4. 貢献するには：agents/<lang>/README.md を編集または追加して、プルリクエストを作成してください。

例
- 現在、このリポジトリには実行可能なサンプルエージェントは含まれていません。agents/examples/<language>/ に例を追加できます。
